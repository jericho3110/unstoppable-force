# File types

| File | What it is | Committed? |
| --- | --- | --- |
| `*.py`, `__init__.py` | Python source; `__init__.py` makes `paradox/` and `tests/` packages | yes |
| `Cargo.toml` | the Rust package manifest: name, edition, (no) dependencies, release profile | yes |
| `Cargo.lock` | exact versions of every dependency (here: just the crate itself) | yes (binaries commit their lock file) |
| `src/lib.rs`, `src/main.rs` | Rust library (+ its tests) and the binary that uses it | yes |
| `*.hpp`, `*.cpp` | C++ header (the templates) and sources | yes |
| `.gitship.json` | which checks gate a commit | yes |
| `.gitignore`, `.gitattributes` | what git ignores; line-ending rules | yes |
| `out/report.md`, `out/paradox.svg` | generated by `python main.py report` | no |
| `*.exe`, Rust `target/` | build output, kept under `%LOCALAPPDATA%\UnstoppableForce` | no |

**SVG** ("Scalable Vector Graphics") is XML text describing shapes. It scales
without blurring and opens in any browser. `plot.py` writes it by hand.
